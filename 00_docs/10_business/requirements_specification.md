# 要件定義書（requirements specification）

最終更新: 2026-07-09
ステータス: Draft（構想段階）

> 簿記刷題アプリの機能要件・非機能要件の正本。MoSCoW で優先度を管理する。

---

## 1. 目的・背景

日商簿記（全級：3級 / 2級 / 1級）学習者向けの問題演習（刷題）アプリ。
目的は **個人学習 + ポートフォリオ作品**。まず Web、将来スマホアプリ化を見据える。

## 2. ユーザー種別

| ロール | できること |
|--------|-----------|
| 一般ユーザー（user） | 問題を解く、自動採点を受ける、錯題を復習、学習履歴・正答率を見る |
| 管理者（admin） | 題库（問題・勘定科目マスタ）の作成 / 編集 / 削除、公開管理 |

## 3. 機能要件（MoSCoW）

### 3.1 一般ユーザー向け

| 優先度 | 機能 | メモ |
|--------|------|------|
| Must | アカウント登録 / ログイン | メール+パスワード。将来 OAuth |
| Must | 問題演習（級・分野で絞り込み） | 3/2/1級、商業簿記/工業簿記 |
| Must | 仕訳問題の自動採点 | 借方・貸方の勘定科目+金額を判定 |
| Must | 正誤フィードバック + 解説表示 | 間違えた理由が分かる |
| Must | 錯題の一覧・再挑戦 | attempts から集計 |
| Should | 学習履歴 / 正答率ダッシュボード | 分野別の弱点可視化 |
| Should | 選択問題・計算問題への対応 | 仕訳以外の形式 |
| Could | 模擬試験モード（時間制限） | 本番想定の連続出題 |
| Could | お気に入り / ブックマーク | 後で見返す |
| Won't（初期） | SNS共有・ランキング | 後回し |

### 3.2 管理者向け

| 優先度 | 機能 | メモ |
|--------|------|------|
| Must | 勘定科目マスタの管理 | 借方/貸方で選ばせる元データ |
| Must | 問題の作成 / 編集 / 削除 | 仕訳・選択・計算 |
| Must | 仕訳問題の「正解行」入力UI | 借方・貸方を複数行で登録 |
| Should | 公開 / 非公開切り替え（下書き） | 未完成問題を隠す |
| Should | 問題のプレビュー | 公開前に見た目確認 |
| Could | CSV 一括インポート | 問題の大量投入 |

## 4. 非機能要件

- セキュリティ: 管理者機能はサーバー側（DB権限=RLS）で保護。フロント表示制御に依存しない。
- レスポンシブ: スマホブラウザで快適に解ける（将来アプリ化を見据える）。
- パフォーマンス: 演習の遷移・採点は体感即時。
- オフライン: （Could）PWA 化でオフライン演習。
- 保守性: UI とロジックを分離し、機能追加・アプリ化を容易に。

## 5. Out of Scope（今回やらない）

- 決済・課金機能
- 多言語対応（まずは日本語のみ）
- リアルタイム対戦・協調学習

## 6. 著作権上の注意

市販問題集の問題文そのままの転載は著作権リスク。オリジナル作問 or 十分な改変を前提とする。
