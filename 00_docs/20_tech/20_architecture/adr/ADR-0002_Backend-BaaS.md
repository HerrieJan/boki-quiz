# ADR-0002: バックエンド（BaaS / Supabase）

- ステータス: Proposed
- 日付: 2026-07-09

## コンテキスト
一人開発で、認証・DB・権限管理を最小工数で用意したい。ポートフォリオとして設計力も見せたい。

## 決定
第一候補は **Supabase**。まずフロント+モックデータで UI・採点を完成させ（案C）、その後 Supabase に接続する。

## 選択肢と比較
| 案 | 内容 | 長所 | 短所 |
|----|------|------|------|
| A: Supabase | 認証+PostgreSQL+API+RLS 全部入り | 最速・RLSで権限設計を語れる | BaaS 独自作法 |
| B: 自前(Node+Prisma) | 完全自作 | 自由度・BE力アピール | 工数大 |
| C: フロント+モック | まず割り切り | 最速で動くものが見せられる | 永続化なし |

## 結果（トレードオフ）
- ルート: **C → A**。RLS による権限分離をポートフォリオの見せ場にできる。
