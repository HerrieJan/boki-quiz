# ADR-0003: スマホアプリ化の戦略

- ステータス: Proposed
- 日付: 2026-07-09

## コンテキスト
将来スマホアプリ化したい。Web コードをどこまで流用できるかで戦略が変わる。

## 決定
**PWA を先に、必要になったら Capacitor** でネイティブ化する。React Native は今回採らない。

## 選択肢と比較
| 手段 | コスト | 説明 |
|------|--------|------|
| PWA | 低 | ホーム画面追加・オフライン対応。まずこれ |
| Capacitor | 中 | React コードをほぼ流用しストア配信可 |
| React Native | 高 | Web とコード共有しにくい |

## 結果（トレードオフ）
- 設計で「UI / ドメインロジック / データ取得」を分離しておけば移行が容易。
