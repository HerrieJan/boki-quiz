# ADR-0004: 画像取り込みのAI/OCR方式

- ステータス: Proposed
- 日付: 2026-07-14
- 関連: [F-003 画像から問題取り込み](../../../../02_backlog/01_epics/INI-001-mvp/UC-004-admin/Commands/F-003_画像から問題取り込み.md)

## コンテキスト
管理者の問題登録を省力化するため、問題画像から内容を読み取り `QuestionEditor` のフォームを自動入力したい（F-003）。「自前サーバーで重い処理が回る／リソースを食う」懸念があるが、いずれの方式も**画像を外部APIに投げて結果を受け取るだけ**で、自前（Supabase）側の計算負荷は実質ゼロ。費用は外部APIの従量課金のみ。

## 決定
第一候補は **マルチモーダルLLM を Supabase Edge Function 経由で呼ぶ**方式。単なる文字起こしを超えて、問題文・級・論点・正解仕訳まで構造化JSONで得られ、`QuestionEditor` をそのまま埋められるため。APIキーは Edge Function の環境変数に保管し、クライアントに露出させない。

## 選択肢と比較
| 方式 | 精度(日本語) | 自前サーバー負荷 | コスト目安 | 難易度 | 備考 |
|------|------------|----------------|-----------|--------|------|
| ① ブラウザOCR (Tesseract.js) | △ 低〜中 | ゼロ | 無料 | 低〜中 | バンドル増・JP精度が課題 |
| ② クラウドOCR (Google Vision / Azure) | ◎ 高 | ほぼゼロ | 約 $1.5 / 1000枚（無料枠あり） | 中 | 文字起こしのみ・構造化は別途 |
| ③ マルチモーダルLLM (GPT / Gemini) | ◎ 高 | ほぼゼロ | 1枚 数円以下 | 中 | 構造化まで一括。**採用候補** |

## コスト概算（変動するため目安）
| 方式 | 1枚あたり | 200枚登録（個人/ポートフォリオ） | 1000枚/月 |
|------|----------|-------------------------------|-----------|
| Gemini Flash系 / GPT-4o-mini | 約 0.1〜0.3 円 | 数十円（実質無料） | 約 100〜300 円 |
| GPT-4o 等 上位LLM | 約 1〜2 円 | 約 200〜400 円 | 約 1,000〜2,000 円 |
| クラウドOCR | 約 0.2 円（月1000枚まで無料枠） | 無料枠内 | 約 200 円 |

- Supabase の Edge Function 実行・Storage は無料枠で十分。個人利用ならコストはほぼ無視できる。

## 結果（トレードオフ）
- ルート: **①/③ の mock → ③ 本実装**。まず mock で体験を固め、Edge Function で実APIに差し替える（F-003 参照）。
- 実装の肝は「AI呼び出し」ではなく**出力の検証・科目マッピング**。既存の貸借一致チェックと `accounts` を流用する。
- 精度の限界（手書き・複雑な表組み）は「人が確認してから保存」ステップで吸収する。
