# UC-001 問題演習

最終更新: 2026-07-09
ステータス: Draft

> 一般ユーザーが問題を解き、自動採点を受ける中核ユースケース。

## 1. 概要
級・分野を選び、問題を1問ずつ（またはセットで）解く。仕訳問題は借方・貸方を入力し自動採点。

## 2. アクター
一般ユーザー（user）

## 3. シナリオ
| ID | 種別 | 名前 | Feature |
|----|------|------|---------|
| Q1 | Query | 問題取得（絞り込み） | [Queries/F-001_問題取得.md](./Queries/F-001_問題取得.md) |
| C1 | Command | 回答提出・採点 | [Commands/F-002_回答提出採点.md](./Commands/F-002_回答提出採点.md) |

## 4. 受け入れ基準（AC）
| # | 基準 |
|---|------|
| AC1 | 級・分野で問題を絞り込める |
| AC2 | 仕訳問題で借方・貸方を入力できる |
| AC3 | 提出時に自動採点され、正誤と解説が表示される |
| AC4 | 回答が履歴（attempts）に保存される |
