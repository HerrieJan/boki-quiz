# 簿記クイズ

簿記検定（3級・2級・1級）の問題を、画面で解く練習アプリです。React の個人開発です。

仕訳は、勘定科目と金額を借方・貸方に置いて答えます。採点と解説が出ます。間違えた問題はブラウザに残して、あとからやり直せます。

## 起動

```bash
npm install
npm run dev
```

表示された URL（通常は http://localhost:5173/ ）をブラウザで開きます。5173 が使用中のときは、別のポートになります。

型チェックだけする場合:

```bash
npm run typecheck
```

## 画面

- **問題を解く**: 級と論点で絞って解く。仕訳はドラッグかセレクト。選択問題と計算問題もある。
- **間違えた問題**: 間違えたときに残すと、ここに入る。削除もできる。
- **問題を管理**: 問題と勘定科目の追加・編集。この画面の変更は、ページを更新すると元に戻る。

## 技術

- React
- TypeScript
- Vite
- Tailwind CSS
- dnd-kit（仕訳のドラッグ）

問題データは `src/data/questions.ts` の配列です。データベースはまだありません。間違えた問題の id だけ、ブラウザの localStorage に保存します。

## フォルダ

```
src/
  App.tsx                 問題を解く / 問題を管理 の切り替え
  features/quiz/          問題を解く画面
  features/admin/         問題の管理画面
  components/             仕訳の入力、採点結果
  domain/                 型と採点
  data/                   サンプルの問題と勘定科目
```

採点は `src/domain/scoring.ts` です。仕訳は並び順を見ません。借方・貸方で、科目と金額が同じなら正解です。

## まだできていないこと

- ログイン
- 問題のデータベース保存（管理画面で追加した内容は、更新すると消える）
